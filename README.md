# ConversorTime_ChristopherAlexis

# Proposito del proyecto(Conversortime Basico)
El proposito del proyecto es poder realizar conversiones del proyecto  como por ejemplo horas a minutos , Minutos a segundos, Días a horas, Semanas a días

# Tecnologías utilizadas.

Se utilizara solamente java

# Instrucciones de uso.

1 °Ejecutar el proyecto 
2 ° Ingresar el numero de horas/minutos/segundos/dias/semanas, recuerda que tiene que ser en numeros enteros ej. 1 (referente al numero de horas/segundos/horas/dias)
3 ° Se te ira guiando durante el programa , cada que coloques un numero y presiones "Enter" te dara el resultado de la conversion
